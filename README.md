# GameMate Releases

GameMate Windows 游戏 AI 语音陪伴助手的官网和公开发行仓库。

- [官网与下载](https://web3-dark.github.io/GameMate-Releases/)
- [最新发行](https://github.com/web3-dark/GameMate-Releases/releases/latest)
- [安装与服务连接](https://web3-dark.github.io/GameMate-Releases/setup.html)

提供 Windows 11 x64 安装版和便携版。安装版支持在设置中检查更新，下载后确认重启安装；便携版下载新版替换。

本仓库只保存静态官网和发行资产，源码仓库保持私有。桌面安装包不包含 AI 服务端、模型凭据或 ASR 服务。

当前预览版未配置代码签名，运行前请核对官网下载区或 SHA256SUMS.txt 提供的 SHA-256 校验值。
