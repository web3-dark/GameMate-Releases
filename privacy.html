DATA & PRIVACY

数据与隐私

这里说明 GameMate 预览版的主要数据处理方式。你选择的服务部署方式、模型和语音识别供应商，会影响数据的实际流向。

本网站

本网站不设置账号、广告或访问统计脚本，也不主动写入分析 Cookie。页面使用本地图片、样式和脚本。访问网站与下载文件时，GitHub Pages、GitHub Releases 及其基础设施可能处理 IP 地址、请求时间、浏览器信息等连接数据；相关处理适用 GitHub 的隐私说明。

GitHub 隐私说明

桌面设置与本机数据

主题、设备选择、窗口位置和其他应用偏好保存在当前 Windows 用户的本机数据目录。便携版也可能使用用户数据目录，不保证所有数据都位于可执行文件旁边。服务端可保存会话、记忆或诊断数据，具体取决于你的服务端配置。

卸载应用或删除便携版文件，不一定同时删除用户数据或独立部署的服务端数据。清理数据前请先确认需要保留的配置和资料。

文字、声音与游戏画面

你发送的文字会交由已连接的 GameMate 服务处理。启用语音转写时，采集到的音频会发送到配置的语音识别服务。启用画面分析时，所选游戏窗口的画面可能发送给配置的视觉模型。开启相应音频通道后，系统游戏声音或队友语音也可能参与识别和事件分析。

这些功能由实际设置和权限控制：按键说话、持续语音、所选窗口、声音通道和主动建议各有入口；暂停助手可停止持续采集。请不要把“本地界面”理解成“全部 AI 计算离线完成”。

模型、语音识别与服务配置

安装包不内置你的 API Key、模型账户或 ASR 配置。模型凭据应保存在你管理的服务端配置中，不能提交到公开仓库，也不应被放进官网文件或安装包。你选择的模型与语音识别服务可能有自己的记录、保存与训练政策，请在使用前查看相应供应商说明。

默认本地连接地址为 http://127.0.0.1:8787。若自行部署远程服务，应配置适当的访问控制与加密传输；本网站不提供托管 AI 服务。

应用更新

检查或下载更新时，应用会请求项目的 GitHub Releases 发布信息及更新文件。GitHub 可能处理请求所需的网络连接信息。安装版下载完成后需确认重启安装；便携版通过重新下载更新。SHA-256 用于核对下载文件，不代表模型输出或第三方内容经过保证。

反馈与说明变更

问题反馈可通过项目 GitHub 仓库提交。提交截图、日志或语音样本前，请删除 API Key、账户信息以及不希望公开的聊天内容。项目行为发生变化时，本页会随网站发布更新。
