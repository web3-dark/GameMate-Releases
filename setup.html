INSTALL & CONNECT

安装与连接

桌面安装包、AI 服务与语音识别分别部署。下面从安装桌面端开始，说明本地运行所需的步骤。

1. 安装桌面预览版

在 Windows 11 x64 电脑下载本页提供的安装版或便携版。安装版运行后按向导选择安装目录；便携版直接运行下载的 EXE。建议先对照下载区提供的 SHA-256 核对文件。

当前预览包未进行代码签名。Windows 可能显示未知发布者或 SmartScreen 提示；请核对来源与校验值后自行决定是否运行，不要关闭系统安全功能。

Get-FileHash .\GameMate-Setup-0.2.0-x64.exe -Algorithm SHA256

返回下载区

2. 准备本地服务端

桌面应用默认连接 http://127.0.0.1:8787，安装器不会启动该服务。公开发行仓库只提供桌面端和官网，服务端源码与部署包由项目维护者单独提供；如果你已获得源码访问权限，请使用与桌面版本对应的源码标签，在 Windows 终端安装 Node.js 20 及以上与 pnpm 9.15.0 后执行：

corepack enable
corepack prepare pnpm@9.15.0 --activate
pnpm.cmd install --frozen-lockfile
pnpm.cmd build:server

若你没有服务端源码或准备使用托管服务，请联系项目维护者获取对应部署地址。不要从陌生来源下载替代服务端。

3. 配置模型并启动服务

在项目根目录从示例创建本机配置：

Copy-Item .env.example .env

使用文本编辑器打开 .env，填写你有权使用的模型服务地址、模型名和 API Key。不要提交或公开这个文件。以下只列出相关配置项，不包含可直接使用的凭据：

HOST=127.0.0.1
PORT=8787
OPENAI_API_KEY=
OPENAI_BASE_URL=
REASON_MODEL=
ASR_URL=http://127.0.0.1:8810

完成配置后启动服务。终端需保持运行；这不会自动安装或启动语音识别模型。

pnpm.cmd start:server

没有模型凭据时，界面和部分本地降级功能仍可运行，不代表在线 AI 对话已经连接。

4. 检查连接和语音

打开 GameMate，在设置的运行诊断中检查服务、模型、ASR 和声音状态。也可在终端检查服务健康接口：

Invoke-RestMethod http://127.0.0.1:8787/health

文字 AI 对话依赖模型服务。按键说话与持续语音的转写还需要单独部署 Qwen3-ASR 兼容服务，并设置正确的 ASR_URL。语音播报使用本机可用的系统声音。ASR 未连接时请先使用文字对话，不要把系统播报成功当作语音识别已经正常。

默认安装包的服务地址在构建时配置；如需其他地址，需重新构建桌面端并设置 VITE_SERVER_URL。本预览版不提供托管 AI 服务。

5. 更新桌面与服务

安装版可从设置中检查更新，下载后由你确认重启安装。便携版通过重新下载更新。服务端独立更新；更换桌面版本时，请对照更新日志同步构建对应服务端，保留你自己的配置。
